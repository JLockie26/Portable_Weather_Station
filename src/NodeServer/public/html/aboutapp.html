About this Project

This project is a personal challenge to take some of what I have learnt within my degree, as well as topics I am not too familiar with, and build something I could use at home or out and about.
This combination of a portable weather station and a personal web application allows a user to monitor conditions both inside and outside (depending on the casing you store the station in) and keep a log of the weather for review and comparison!

If you are a user of this project, I hope the setup was easy to follow and you were able to get the Arduino code working on your device :)

Goal of Project

  • Demonstrate & revise knowledge of:
    • Object-Oriented Programming
    • Data Structures & Abstractions
    • Basic Web Development

  • Expand knowledge in:
    • Low-Level/Systems Programming
    • Advanced Web Programming
    • Client-Server Architecture
    • Electronics

Current Functionality

  • Arduino Weather Station
    • Attempts WiFi Connection
    • Successfully Logs Weather Measurements
    • Sends Weather Logs to Local Web Server (if connected to WiFi)
    • Currently Displays Readings on OLED Screen (subject to change)
  • Local Web Server
    • Displays Single Page Application
    • Monitors most recent Weather Log
    • Automatically Updates Live Log
    • Weather History Currently in Works
